# API reference

Import the Go package as `installer "github.com/deedima3/wails-installer"`.

## Config

| Field | Type | Behavior |
| --- | --- | --- |
| `ID` | `string` | Required portable identifier. Lowercase ASCII letters, digits, dots, hyphens. Starts with a letter or digit, maximum 128 characters. Cannot be a Windows reserved filename or end in a dot. Used in paths and login entries. |
| `Name` | `string` | Required display name. |
| `Version` | `string` | Required version text. |
| `Description` | `string` | Optional sidebar copy. |
| `Payload` | `fs.FS` | Required trusted source filesystem, already rooted at the payload. Prefer `fs.Sub` on `embed.FS`. |
| `Executable` | `string` | Required slash-separated relative payload path. Must exist as a regular file. Gets executable permissions. |
| `Executables` | `[]string` | Additional relative paths that need executable permissions. |
| `DefaultDirectory` | `string` | Absolute new install path. Empty chooses the platform default. |
| `AllowStartup` | `bool` | Makes the login option available. False by default and enforced by the backend. |
| `MaxBytes` | `int64` | Maximum total payload size. Zero uses 2 GiB. Does not include files generated by hooks. |
| `Hooks` | `Hooks` | Optional `BeforeCopy` and `AfterCopy` functions. |

`New(config, options...) (*Installer, error)` validates configuration. Payload inspection happens at installation, so construction can succeed while the payload is missing its configured executable. Options are `WithStartupManager` and `WithLauncher`. A nil required implementation produces an error.

`Installer.Info() Info` returns application metadata, the default path, startup availability, and the current `runtime.GOOS` platform string.

`Installer.Install(ctx, request, report) (Result, error)` performs a fresh install. `report` is an optional synchronous `func(Progress)`. It must be fast and must not panic. Concurrent calls on the same engine return `ErrBusy`. Separate engines targeting the same path coordinate through a sibling lock directory. Context cancellation is checked between files and copy chunks, before publication, and by startup registration. Once publication succeeds without a requested startup entry, or registration succeeds, installation is committed.

## Service

`NewService(engine, picker) *Service` creates a binding-safe wrapper. A nil engine is a programmer error and panics. The optional `DirectoryPicker` has type `func() (string, error)`.

| Method | Result | Behavior |
| --- | --- | --- |
| `Info()` | `Info` | Read configuration metadata. |
| `State()` | `State` | Read a concurrency-safe snapshot of progress and outcome. |
| `Browse()` | `string, error` | Invoke the supplied directory picker. Empty string means dismissal. Nil picker returns an explanatory error. |
| `Install(Request)` | `Result, error` | Run installation. State changes to `installing` before the copy. Only one request runs at a time. |
| `Cancel()` | none | Request cancellation. Safe while idle. Cleanup completes before `Install` returns. |
| `Launch()` | `error` | Start the last successful install's executable. Refuses calls before success or after a subsequent failed install. |

State is held in memory. Restarting the installer begins with `ready`; it does not inspect old installations. Calling `Install` again clears the previous result. Keep the installed app's settings and upgrade logic in your own application.

## JSON and TypeScript contract

The frontend package exports `Installer`, `createClient`, `InstallerBindings`, `BindingState`, `InstallerClient`, `InstallerInfo`, `InstallerState`, `InstallRequest`, `InstallResult`, and `Progress`.

```ts
interface InstallRequest {
  directory: string; // Absolute destination that must not exist.
  startup: boolean;
}

interface InstallResult {
  directory: string;
  executable: string;
  startup: boolean;
}

interface Progress {
  phase: string; // preparing | copying | finishing | complete
  file: string; // Payload-relative path, blank outside copying.
  copiedBytes: number;
  totalBytes: number;
  percent: number; // 0..95 during copy, 97 finishing, 100 complete.
}

interface InstallerState {
  status: 'ready' | 'installing' | 'complete' | 'error' | 'cancelled';
  progress: Progress;
  error: string;
  result: InstallResult | null;
}

interface InstallerInfo {
  id: string;
  name: string;
  version: string;
  description: string;
  defaultDirectory: string;
  allowStartup: boolean;
  platform: string;
}
```

`InstallerBindings` contains PascalCase methods matching Go. All return promises through Wails. Its `State` result uses `BindingState`, which accepts the broad string status and optional result emitted by Go binding generators. `createClient(bindings)` validates the status and normalizes a missing result to null. It returns lower-case `info`, `state`, `browse`, `install`, `cancel`, and `launch` methods. A custom client can use any transport with the same return types.

## Svelte component props

| Prop | Default | Purpose |
| --- | --- | --- |
| `client` | required | An `InstallerClient`. Keep its identity stable while the component is mounted. |
| `eyebrow` | `APPLICATION SETUP` | Small heading text. |
| `logoUrl` | empty | Optional brand image URL. |
| `className` | empty | Extra root CSS class. |
| `onInstalled` | undefined | Callback after a successful installation initiated by this component. Receives `InstallResult`. |

The component supports named `sidebar` and `footer` slots. Theme variables are listed in [customization](customization.md). It restores the current service state when mounted, polls during installation, and cleans up its polling timer on unmount. Launch failures remain visible in the completed screen so the user can retry.

## Errors and filesystem behavior

Go errors wrap the underlying cause where possible. Use `errors.Is` for `context.Canceled` and `ErrBusy`. Wails may reject JavaScript promises with a string rather than an `Error`; custom UIs should handle both.

The installer refuses existing destinations, unsafe payload paths, symlinks, special files, case collisions, oversized payloads, missing entrypoints, and conflicting startup registrations. It checks copied bytes against the inspected file size. It does not hash or authenticate the payload. Hooks can add files without changing the byte progress total.

Errors returned by hooks abort before publication. If startup registration fails after publication, the installer removes its newly installed directory. Cleanup errors are joined into the returned error, so callers can report filesystem recovery work. See [limitations and recovery](integration.md#limitations-and-recovery).
